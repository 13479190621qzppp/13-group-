# 随音 · 乐器练习室

面向“乐器跟弹与键位提示”的课程设计工程：原有前端完整保留，新增 **Node.js 规范化曲谱 API、按键会话判定、离线音符匹配**，并提供可选的 **Python Spotify Basic Pitch 音频转录服务**。浏览器依然即时发声和判定；按键事件旁路同步至后端进行同规则服务端对照。无需登录、数据库或 npm 依赖安装。

**新功能的 Windows 一步步安装、接口格式及延迟测试，请优先阅读 [`README-后端模型.md`](README-后端模型.md)。**

## 启动

电脑已安装 Node.js 18 或更新版本时，双击 `启动随音.bat`，保持终端开启，在 Chrome / Edge 打开 http://localhost:5173 。也可在本目录运行：

```powershell
node server.cjs
```

不要用 `file://` 直接打开 index.html，浏览器模块和采样需要 HTTP 服务。端口被占用时，先查看是否已有本项目服务；或在 PowerShell 中执行 `$env:PORT=5174` 后 `node server.cjs`。

## 已实现

- C3–C6 多八度钢琴，尼龙弦吉他 0–12 品指板；两种本地 MP3 采样音色；独立音量控制。
- 鼠标、触屏（支持多点）、电脑键盘与 Web MIDI 四种输入的统一事件。长按去重、滑奏、失焦松键与自动暂停。
- 4 首内置练习；导入未压缩 MusicXML；简化五线谱、按音高排列的瀑布流；当前小节光标与提前 2 / 3 / 5 组目标预告。
- 等待模式、带三拍预备的跟弹模式、自动示范；暂停、继续、重置、节拍器和 30–200 BPM 速度设置。
- 独立跟随内核；钢琴和吉他适配描述；按键或弦品提示；错音、漏音、多音和抢拍 / 拖拍记录。
- 时间容差、和弦聚合窗口、指定小节区间循环。
- 实际练习数据生成报告：正确率、完成度、错误小节明细、等待超时统计、有效时长；最近 30 次本地历史；JSON 导出。
- 桌面、平板、手机布局与使用指南。

## 三分钟演示

1. 首页选择默认《小星星》和等待模式，点“开始练习”。按 `A A G G H H G` 弹第一句。`A` 对应 C4，`G` 对应 G4，`H` 对应 A4。
2. 故意按一个错误音，琴键和谱面会标红，当前位置保留。弹对后继续。
3. 点“结束并生成报告”，查看正确率、错误音高、错误小节与完成度。
4. 回到工作台，切换吉他，查看目标弦品位置。使用同样的电脑键盘输入可推进同一个跟随内核。
5. 曲谱库选择“和弦小练习”；第一组按齐 `A D G`，即 C4 / E4 / G4。三音需要在 160 ms 默认窗口内完成。
6. 切换跟弹模式，经过三拍预备后故意不弹，观察漏音记录；演示模式可自动播放曲谱。
7. 导入同目录 `示例曲谱.musicxml`，验证休止符、四小节谱面与载谱流程。

## 本版边界

当前版本已经提供 Node.js 后端 API 与可选 Python Basic Pitch 模型服务部署代码，但浏览器练习仍由本地内核即时驱动，后端是旁路验证。离线 WAV 转录模型与 HTTP 接口的代码已完成，目标设备仍须安装 Python 依赖并实际验证，不能当作已经完成 Windows 模型性能验证。跟随采用规则时间窗口，不具备 Matchmaker 的复杂跳奏、自由速度估计或失步重定位。

MusicXML 导入支持第一乐器、单声部、同起点等时值和弦、基础升降号和延音线；复杂多声部、移调乐器、反复展开、中途变拍号、压缩 MXL 和 Guitar Pro 不支持。谱面采用简化高音谱表，按实音显示临时升号，不完整还原原文件排版、连梁、连音线或指法标记。超过当前乐器可见音域的曲谱可查看，但练习开始时会提示更换曲谱或乐器。两份适配描述以键盘与弦品映射为示例，新增完全不同的乐器外观仍需对应渲染器。

MIDI 必须在浏览器支持的安全上下文中使用，并由用户授权；没有实际设备时仍可使用网页乐器。电脑键盘可同时按键数量受硬件冲突限制，触屏与 MIDI 可作为和弦输入替代。没有真实设备时不宣称完成硬件兼容验证。

本地保存的报告使用当前站点来源区分，`localhost` 与 `127.0.0.1` 的记录不互通。记录可导出；清除浏览器数据会清除历史。音色授权见 `THIRD_PARTY.md`。
